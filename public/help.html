PRIV Agent

Your assistant in the browser. Open the side panel, connect a tool calling model in Settings, and describe a task.

Connect a model

  1. Open Settings → Providers.
  2. Add OpenAI-compatible, Ollama, LM Studio, or another supported provider.
  3. Enter the endpoint, model ID, and key if needed. Run Test models and pick a default model.

Research and messaging

Ask for a summary with sources. Review the pages and links before using a report. If you ask the agent to send a WhatsApp message, check the contact and complete draft in WhatsApp Web before approving the action card. The extension will not bypass sign-in.

Controls

Use Stop to cancel the current task. Settings → Permissions controls site access and Ask/Auto behavior. WhatsApp Web writes always require fresh approval.
